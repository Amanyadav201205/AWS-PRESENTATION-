# WAF Presentation Script Versions

Three optimized versions of the presentation script are available for different time constraints and audience types.

## Versions at a Glance

| Version | Lines | Duration | Use Case |
|---------|-------|----------|----------|
| **Original** | 70 | 21 minutes | Deep technical training, detailed Q&A |
| **Balanced** ✅ | 38 | 17-18 minutes | Executive pitch, client presentation (RECOMMENDED) |
| **Ultra-Condensed** | 24 | 12-13 minutes | Quick demo, short webinar slots |

---

## Which Version to Use?

### **Balanced (38 lines, 17-18 min)** — RECOMMENDED
**Best for:** Executive presentations, client pitches, webinars with Q&A
- **File:** `WAF-PRESENTATION-SCRIPT-BALANCED.md`
- **Pros:** Professional pacing, keeps all 15 modules with depth, all metrics and examples, natural flow
- **Perfect for:** 15-20 minute time slots with board/C-suite audiences
- **Read time:** Sounds natural at 140 WPM, not rushed

### **Original (70 lines, 21 min)**
**Best for:** Technical training, architect workshops, deep dives
- **File:** `WAF-PRESENTATION-SCRIPT.md` (current file)
- **Pros:** Full technical detail, separate theory + comparison sections, breathing room
- **Perfect for:** 20-25 minute slots where audience wants comprehensive explanation
- **Read time:** Very comfortable pace with room to pause and emphasize

### **Ultra-Condensed (24 lines, 12-13 min)**
**Best for:** Quick demos, elevator pitches, short webinar slots
- **File:** `WAF-PRESENTATION-SCRIPT-CONDENSED.md`
- **Pros:** Hits all 15 modules, super tight, all key metrics
- **Perfect for:** 10-15 minute hard time limits
- **Read time:** Brisk but clear at 140 WPM

---

## Content Comparison

All three versions retain:
- ✅ All 15 AWS Well-Architected modules
- ✅ All real-world scenarios (ransomware, flash sales, database crashes, regional outages)
- ✅ All critical metrics ($4,450→$1,820, 98.5%→99.99%, RTO 4-8hrs→30sec)
- ✅ All live simulation comparisons (naive vs. Well-Architected)
- ✅ Final executive scorecard

**Differences:**
- **Original:** Separates problem + solution + simulation into distinct callouts per module
- **Balanced:** Combines problem + solution in one line, simulation result in next (still clear)
- **Ultra:** Everything densely packed into one line per module (assumes slides carry narrative)

---

## How to Switch Versions

### For Presenter Notes
Simply open whichever file matches your time slot and copy the lines into your presentation software speaker notes.

### For Live Presentation
Use the `?present=1` query parameter on the site to activate presenter mode. The script is embedded in each slide's speaker notes.
